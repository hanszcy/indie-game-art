# Original design plates

These are original art-direction studies for this skill. The generated color key and editable vector plates explore a fictional parcel game. Their figures and timings belong to that setting. A second, independent study uses two captures from an interactive dye yard.

- [Harbor color script](harbor-color-script.webp) explores the same location in three weather conditions. Compare how far contours, reflected light and open water frame the figure. Use it as a concept comparison at thumbnail size.
- [Stamp control](stamp-control.svg) tracks ready, contact, pending and confirmed faces against one fixed hit rectangle. Substitute a real icon and the longest supported label. Try the row at its intended device size.
- [Last delivery](last-delivery.svg) follows the same parcel into an ordinary clear or a missed departure. Trace the cause, settled record and return action on each branch. Change the consequence for a checkpoint game or a long run before budgeting illustrations.
- [Motion exposure sheet](motion-exposure.svg) aligns pose, rule event, feedback and input availability. The columns show event order; their spacing is schematic. Replace the illustrative timings with measurements from the target build. The reduced-motion track preserves contact and outcome.
- [Wind in a dye yard](../../references/cloth-field-study.md) compares a cloth corner secured in a wooden peg with the same corner slipping loose. Read the two original captures side by side at phone size.

Use the [study sheet](../study-sheet.md) to record where the decision came from and whether it worked in play.
