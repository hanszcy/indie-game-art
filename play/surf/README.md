# 浮世绘冲浪 · 两版竖屏

`plain/`《浪间一日》由未读取美术 Skill、未查看优化版的独立执行者制作，独立 Canvas 渲染；`skill/`《潮生》使用 indie-game-art 3.1.0。两版共享 `shared/engine.js` 的确定性规则，但呈现代码各自独立。

从仓库根运行静态服务器后打开 `/play/surf/`。开始后按住海面或底部按钮蓄力、松开起跃；空格键也可操作。P 暂停。收集海螺、避开礁石及漂木，3点体力，抵达800米终点。

物理以1/120秒步长推进。接触点使用随时间变化的 water(x,time)，板面朝向由同一表面的切线计算；起跃后遵循重力，重新接触浪面时吸收着水动作。两版可在相同按键输入下完成800米、3点体力、24枚海螺、12次起跃。

验证：`node play/surf/shared/engine.test.mjs`；真实浏览器完整开始、蓄力、跃浪、暂停/继续、重新开始、胜负状态；390×844、360×740及320×640竖屏检查。触摸通过浏览器原生触摸事件验证。尚未做实体手机Safari验证。

素材投入：普通版0次图片生成、0外部下载；Skill版2次图片生成（横幅探索1次、竖幅重构1次），最终仅使用原创 `skill/assets/sea-print.png`。动态人物、冲浪板、浪面、礁石、漂木、海螺为自绘 Canvas。素材投入不等，不宣称受控实验。
