# 浮世绘冲浪 · 两版竖屏

`plain/`《浪间一日》为未读取美术 Skill 的独立普通版；`skill/`《潮生》使用 indie-game-art 3.2.0 完成整套海湾美术重绘。两版共享 `shared/engine.js` 的确定性规则，呈现代码独立。

从仓库根运行静态服务器后打开 `/play/surf/`。按住海面或底部板形控件蓄力，松开起跃；空格键可操作，P暂停。收集海螺、避开礁石及漂木，3点体力，抵达800米终点。

新版人物为宽帽、短外套、蓬松裤形的海行者，四张透明关键姿态覆盖六个动作阶段。海湾、角色、动态浪面、障碍物、螺壳、归港入口与界面均重新制作。素材压缩为WebP，约1.6 MiB；旧海景未继续使用。

验证：真实浏览器完整开始、蓄力、起跃、着水、暂停/继续、重开、胜负；390×844、360×740、320×640及320×568检查；触摸取消、键盘焦点、满蓄力、减少动态、加载失败处理。相同按键回放，两版仍达到相同800米、3体力、24海螺、12跳。未实测实体手机Safari。
