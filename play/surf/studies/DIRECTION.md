# 潮生 · 海湾重绘

使用 indie-game-art 3.2.0，读取主指引及 visual-language、picture、performance、interface、production、continuity。此次用户明确否定旧人物并要求整套美术重做，因而重新打开造型方向，而不是延续旧图叠加滤镜。规则、视角和输入保持；普通版没有修改。

## 从可见问题到绘制选择

旧版精细远浪、线段拼接人物和光滑前景分属不同视觉系统。新版从人物的比例、衣形和负形开始：宽而低的草帽、短发下的小脸、宽袖短外套与蓬松裤形，腰侧与手臂之间留出清楚的空隙。衣摆和围巾用长尖收尾，裤腿和帽体用宽圆体块，避免所有物件都画成同一块形状。色彩承担分工：青绿水体、靛蓝衣服、象牙裤形，少量朱红留给围巾和板纹。

[造型与动作试样](directions.html) 的第一张图是在同一主题、色组与冲浪局面中比较紧凑低重心和修长长衣构造。采用前者，因为手机尺寸仍能分清帽、脸、膝盖和板；后者的舒展长衣更流动，但细肢体和开口在小尺寸较弱。试样为探索图，不是声称精确匹配每个像素的受控实验。

## 场景、配角与界面

新海湾将山岛放在左侧，灯塔与港口留在右侧，中部水面安静。人物前方不再堆叠细密浪沫。新近景使用宽缓的曲面、分组刻线、沿水面运动的泡沫和克制的油墨颗粒；礁石以暗色圆体和单一折口构成，漂木用少数纵纹，海螺用清楚的旋纹。远近物体共享边缘与色块关系，但远景降低对比，近景障碍保留轮廓。

标题由旧竖框改为海面上方的横排；里程与太阳错开。开始、继续、重玩及蓄力入口均重画成有朱红尾纹的细长板形；底部控件与角色脚下的板互相呼应。声音、暂停、返回保留通用意义及语义按钮，触摸区域不随绘制的受力位移改变。加载未完成时入口不可用，失败时显示明确提示。

## 人物与动作

最终有四张透明关键姿态：滑行、深蹲、腾空平衡、归港挥手。它们覆盖滑行、蓄力、起跳、下降、着水和归港六个阶段。蓄力/着水共用深蹲，起跳/下降共用腾空姿态并按垂直速度调整板角；不是六张独立图片，也不是连续骨骼插值。每张以板面接触点对齐。不同姿态的细部纹样与脸部存在生成差异；在实际尺寸检查过，保留为关键姿态切换的限制。

动作试样页面实时比较“单姿态随板运动”和“关键姿态随力变化”，共享同一次物理模拟。选择后者；着水浪沫只在真实接触点出现，海螺拾取有局部上行消散，不用全屏脉冲。减少动态模式保留必要的角色和物理运动，取消附加喷沫与背景漂移。实际触摸录屏在 [action.html](action.html)。

## 来源与转译

[大都会博物馆《神奈川冲浪里》说明](https://www.metmuseum.org/art/collection/search/45434)讨论了近浪与远山的尺度关系。这里采用“近处动作清晰、远处目的地安静”的空间层次；没有把馆藏扫描图当背景，也没有复制大浪构图。版画观察转译成轮廓、少数刻线和成组平涂，纹理本身不是风格成立的证据。

[Andreas Illiger 的 Tiny Wings 官方页面](https://www.andreasilliger.com/)描述单按钮借地形起跃、随重力返回的循环。这里保留已有冲浪规则，从中研究“压低—离开支承—重新接触”的动作可读性，不使用该游戏的角色、画面或音频。

## 素材、提示词与交付

使用内置 imagegen，未使用 CLI/API。本轮最终采用六份输出：一张造型比较、一张背景、四张人物姿态；有网络失败的生成/编辑调用，未采用其结果。试图直接编辑透明动作图时多次网络失败，最终采用单张姿态生成并做接触点对齐，因此不宣称所有细部逐帧一致。

- 运行资产：`../skill/assets/coastal-bay.webp`、`rider-cruise.webp`、`rider-crouch.webp`、`rider-air.webp`、`rider-greet.webp`。
- 原图对应关系和完整最终提示词：[rebuild/prompts.md](rebuild/prompts.md)。WebP 使用 cwebp 质量88、alpha质量100编码；没有用色键去背，透明度来自生成文件的 alpha。
- 动态浪面、礁石、漂木、海螺、终点、喷沫：`../skill/art.js`；界面：`../skill/index.html` 与 `style.css`。
- 五张运行位图合计约1.6 MiB；保留本地原始PNG，网页加载压缩版本。
- 旧背景和旧人物已退出运行路径，旧版本保存在 Git 历史中。普通版的素材投入与本版不同，不能视为严格因果实验。

## 验证

Chrome 手机视口390×844、360×740、320×640：真实触摸蓄力、起跳、落水与布局；同一按键回放完整通关，两版同为800米、3体力、24海螺、12跳。覆盖暂停/继续、触摸取消、满蓄力、键盘焦点、重开、胜负和减少动态模式，无运行时错误。另检查320×568短屏、素材加载失败与实时造型试样。未进行实体手机Safari测试。美术是否合口味仍由玩家判断，功能验收不能代替审美反馈。
