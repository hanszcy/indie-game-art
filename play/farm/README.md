# 农场消消乐

本地运行：`python3 -m http.server 4175 --bind 127.0.0.1`，打开 http://127.0.0.1:4175/。

- `plain/`：独立普通版，未读取美术技能；本轮未修改。
- `skill/`：小满菜园，使用 indie-game-art **3.2.0** 制作美术与采摘表现，并重新绘制游戏控件。
- `shared/core.js`：共享规则，7×7，seed43，24步，1800分；本轮未修改，无效交换不扣步。
- `studies/style-comparison.html`：同一个初始棋盘上，两套原创画法的实际尺寸比较。
- `studies/action-comparison.html`：直接入篮与飞行入篮的动作比较，以及输入、传递、静止结果的实机截图。
- `studies/DIRECTION.md`：选择依据、引用、剩余限制。

新版资产是可编辑的原创 SVG，不依赖旧水粉场景或图集。母版和重建脚本在 `studies/draw-assets.py`；运行 `python3 studies/draw-assets.py` 可重建两套图集和造型比较页。旧 WebP 留作历史，不在新版运行时使用。

交互：点选、轻扫相邻交换、方向键与回车；提示、拒绝回弹、逐波连锁、按列下落、重开、胜负结算、可选音效。收获篮保留最多6个代表性作物；积分显示精确结果。减少动态模式直接显示收获。结算等最后一批落篮，中途重开取消旧局的动作。

已验证：Chrome手机模拟390×844、360×740全屏布局；360×640、320×568窄短屏无横向溢出（短屏可纵向滚动）。有效/无效交换、真实触摸滑动、键盘、提示、7波连锁胜利、结算后重开、动画中途重开、减少动态模式，均通过断言；无页面脚本错误。未进行实体手机Safari测试。

两版规则与初始棋盘一致。seed43有一步多连锁可达标的组合，本轮为美术重做，未改变玩法平衡。两版并非严格因果实验。

3.2 控件检查：Chrome 手机模拟 390/360/320 宽度下，点击区与篮子、棋盘互不重叠；按压、移出取消、触摸取消、键盘焦点、提示忙碌禁用、声音状态均通过。原有交换、采摘、连锁结算与重开检查通过。
