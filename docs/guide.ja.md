# Indie Game Art の使い方

磨きたい一場面を選びます。プレイヤーは何を見て、手をどう動かし、その瞬間に何を感じてほしいでしょうか。すでに決まっているルールやカメラ、気に入っている絵を判断の基準にします。[英語のスキル本文](../skills/indie-game-art/SKILL.md)

**絵に個性が出ない。** 魚を待つ一羽のサギを二通りに描きます。片脚で首を伸ばす姿と、首をたたんで低く構える姿。遊ぶときの大きさで見比べると、魚を突く直前の緊張が伝わるのはどちらでしょうか。[サギの二つの構えと動き](../skills/indie-game-art/plates/bird-study.svg) · [構図・素材・人物](../skills/indie-game-art/references/picture.md)

**操作画面がウェブページに見える。** 一つの判断を追います。二枚の書類を照合するなら並べて置きます。判を押すこと自体に手応えがあるなら、プレイヤーにスタンプを持たせます。[『Papers, Please』などに見る画面づくりの判断](../skills/indie-game-art/references/field-notes.md)

**言葉がぎこちない。** 台詞、ステータス表示、結果の通知を続けて読み、一文を隠すと何が失われるかを確かめます。登場人物がようやく口にした一言には、読む時間を残します。扉が開いたことを三度も知らせていたら、一つ削れます。[操作画面とことば](../skills/indie-game-art/references/interface.md)

**静止画はよいのに手応えが薄い。** 押した瞬間、ゲームが結果を決める瞬間、次に操作できる瞬間を追います。どこに力がかかり、どの音が先に消えるでしょうか。無音、連続入力、中断で試し、動きが収まった後にも何が起きたか分かるかを確かめます。[動きと反応](../skills/indie-game-art/references/performance.md)

ゲーム全体を扱うときは、入り方、終わり方、もう一度遊んだときの気分まで見ます。同じカメラと同じ局面で比較し、絵から読み取ったことと、実際のプレイで確かめたことを分けて伝えます。[場面のつながり](../skills/indie-game-art/references/continuity.md) · [調査と講評](../skills/indie-game-art/references/critique.md)
