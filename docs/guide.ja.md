# Indie Game Art の使い方

磨きたい一場面を選びます。プレイヤーは何を見て、手をどう動かし、その瞬間に何を感じてほしいでしょうか。すでに決まっているルールやカメラ、気に入っている絵を判断の基準にします。[英語のスキル本文](../skills/indie-game-art/SKILL.md)

**遊びはできたが、絵が決まらない。** 同じ場面を同じ距離から二通りに描きます。停電した図書館なら、一つの灯りが二人の読者を近づける絵も、ひとりの机を暗闇に浮かべる絵も成り立ちます。遊ぶときの大きさで見比べ、そのゲームで描きたい関係を選んでから家具や布地を詰めます。[構図・素材・人物](../skills/indie-game-art/references/picture.md)

**絵はあるが、操作画面だけウェブサイトのように見える。** 一つの判断に必要な情報を追います。数値の比較には整った表が向きます。手で触れる道具なら、道具自体の変化で結果が伝わることもあります。見えている動作を繰り返す説明は一度外し、登場人物がようやく口にした一言には、読み終えて余韻を味わう時間を残します。[操作画面とことば](../skills/indie-game-art/references/interface.md)

**静止画はよいのに手応えが薄い。** 押した瞬間、ゲームが結果を決める瞬間、次に操作できる瞬間を追います。どこに力がかかり、どの音が先に消えるでしょうか。無音、連続入力、中断で試し、動きが収まった後にも何が起きたか分かるかを確かめます。[動きと反応](../skills/indie-game-art/references/performance.md)

ゲーム全体を扱うときは、入り方、終わり方、もう一度遊んだときの気分まで見ます。同じカメラと同じ局面で比較し、絵から読み取ったことと、実際のプレイで確かめたことを分けて伝えます。[場面のつながり](../skills/indie-game-art/references/continuity.md) · [調査と講評](../skills/indie-game-art/references/critique.md)
