# 在自己的游戏里使用 Indie Game Art

[回到案例](../README.zh-CN.md) · [完整英文工作流](../SKILL.md)

1. **给一个可玩的瞬间。** 告诉 Codex 从哪个页面进入、点哪里、应该看到什么。附上目标设备尺寸，以及已经认可的角色或规则。
2. **让参考解决一个问题。** 例如观察画面如何区分近处的塔和远处的敌人，或一次命中之后玩家该看哪里。静态截图适合研究轮廓，动作先后需要看录像或实机。
3. **先改一个动作。** 固定地图、输入和数值，把塔的待机、发射、命中做全。在手机上看第一次反应、最亮的一帧，以及反馈结束后还能不能看清下一只敌人。
4. **扩展到整局。** 确认代表场景后，把同一套颜色、轮廓和材质用到选塔、暂停、遗物和结算。数值和命中范围始终由游戏逻辑决定。
5. **用相同条件回看。** 记录改动前后的一次相同操作，再试连续点击、中途暂停、失败局面和减少动态效果模式。交付时写明检验过的平台。

示例请求：

> 用 $indie-game-art 检查手机端的选塔流程。先确认我是否看得出哪座塔被选中、在哪建造、铜币不够时是什么状态。先打磨火花塔，再把通过验收的处理扩展到另外两座塔。
