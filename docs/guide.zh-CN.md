# Indie Game Art 使用指南

从你要打磨的那一刻开始。玩家在看谁，手上正做什么，希望这一刻让人产生什么感觉？游戏已有的规则、视角和喜欢的美术，会成为取舍的依据。[英文 Skill 正文](../skills/indie-game-art/SKILL.md)

**角色缺少辨识度。** 把同一只等鱼的鹭画两次。一种伸长脖子，单脚站着。另一种缩起脖子，压低身子。缩到玩家实际看到的大小，哪种姿态更能让人屏息等它出击？[鹭的两种姿态与捕鱼动作](../skills/indie-game-art/plates/bird-study.svg) · [构图、材质与角色](../skills/indie-game-art/references/picture.md)

**界面很像网页。** 跟着玩家做一次选择。两份证件需要核对，就把它们并排放。如果乐趣在于亲手盖章，就让玩家拿起印章。[《Papers, Please》等作品的界面取舍](../skills/indie-game-art/references/field-notes.md)

**文字读着生硬。** 把台词、状态栏和结果提示连起来读。先遮住一句，看少了什么。角色难得说出口的一句话值得留时间听，第三次提醒门开了就可以删。[界面与文案](../skills/indie-game-art/references/interface.md)

**静态画面满意，动起来却不对。** 看清玩家按下、游戏判定、结果落定以及下一次允许操作的时刻。再看受力的是哪个部位、哪个声音该先停。用静音、连续操作和中断来检验，观察效果结束后还能否理解发生了什么。[动作与反馈](../skills/indie-game-art/references/performance.md)

完整项目还可以看一次进入、一次离开，以及重试后的感受。对比画面务必使用相同的镜头和状态。指出具体的得失，再区分哪些来自作者判断，哪些已经在实际游玩中观察到。[场景衔接](../skills/indie-game-art/references/continuity.md) · [研究与评图](../skills/indie-game-art/references/critique.md)
