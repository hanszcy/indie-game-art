# Indie Game Art 使用指南

从你要打磨的那一刻开始。玩家在看谁，手上正做什么，希望这一刻让人产生什么感觉？游戏已有的规则、视角和喜欢的美术，会成为取舍的依据。[英文 Skill 正文](../skills/indie-game-art/SKILL.md)

**玩法已成形，美术尚未确定。** 固定同一场景的镜头和角色大小，试两种都说得通的构图。比如停电后的图书馆，一盏灯能让两个陌生人坐近，也能让独自看书的人显得与四周隔绝。游玩尺寸下看两张图，先决定哪种人与空间的关系属于你的游戏，再画桌椅和衣料。[构图、材质与角色](../skills/indie-game-art/references/picture.md)

**美术已有方向，界面却很像网页。** 跟着玩家做一次选择。需要同时比较的数字可以并排留着，手正碰到的东西可以自己做出回应。一段话如果只把已经看见的动作解释一遍，删掉试试看。如果它是一个角色难得说出口的话，就给它留出说完和被听见的时间。[界面与文案](../skills/indie-game-art/references/interface.md)

**静态画面满意，动起来却不对。** 看清玩家按下、游戏判定、结果落定以及下一次允许操作的时刻。再看受力的是哪个部位、哪个声音该先停。用静音、连续操作和中断来检验，观察效果结束后还能否理解发生了什么。[动作与反馈](../skills/indie-game-art/references/performance.md)

完整项目还可以看一次进入、一次离开，以及重试后的感受。对比画面务必使用相同的镜头和状态。指出具体的得失，再区分哪些来自作者判断，哪些已经在实际游玩中观察到。[场景衔接](../skills/indie-game-art/references/continuity.md) · [研究与评图](../skills/indie-game-art/references/critique.md)
